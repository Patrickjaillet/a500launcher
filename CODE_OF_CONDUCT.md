# Code of Conduct

## Our standards

Everyone interacting in A500 Launcher's issues, pull requests and e-mail is
expected to be respectful. Examples of acceptable behaviour: being welcoming,
accepting constructive feedback, focusing on what is best for the project.

Unacceptable behaviour includes harassment, insults, discriminatory language,
publishing others' private information, and sustained disruption.

## Scope

This applies in all project spaces (the repository, issues, pull requests) and
when an individual is representing the project in public.

## Enforcement

Report unacceptable behaviour to **sandefjord.development@proton.me**. Reports are
handled confidentially. The project maintainer may remove comments, reject
contributions, or block accounts for behaviour that violates this code.
